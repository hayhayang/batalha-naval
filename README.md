# Batalha Naval em C

Este é um jogo simples de Batalha Naval desenvolvido em linguagem C, utilizando matrizes, loops e condicionais. Foi criado para fins acadêmicos e estudo de lógica de programação.

## Funcionalidades
- Tabuleiro 10x10
- Posicionamento manual ou aleatório dos navios
- Ataques do jogador e do computador
- Verificação automática de acertos
- Fim de jogo com derrota ou vitória

## Estrutura do Projeto
```
batalha-naval/
├── batalha_naval.c
└── README.md
```

## Como Compilar
### Windows (MinGW)
```
gcc batalha_naval.c -o batalha.exe
batalha.exe
```

### Linux/Mac
```
gcc batalha_naval.c -o batalha
./batalha
```

## Como Jogar
1. Escolha se deseja posicionar navios manualmente ou automaticamente.
2. Informe coordenadas para atacar.
3. O computador responde com ataques.
4. O jogo termina quando um dos tabuleiros é destruído.
